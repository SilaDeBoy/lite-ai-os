# Lite AI OS

A simple personal dashboard that runs on **GitHub Pages**.

## Features

- **Dashboard** – Quick overview
- **Job Tracker** – Add and track job applications (you apply manually)
- **AI Assistant** – Helps write cover letters and answers (uses Puter.js when available)
- **M-Pesa Log** – Record payments you make yourself (does **not** send money)
- **Tasks & Notes** – Simple to-do list and notes

## Important Limits

This app **does not**:
- Automatically apply for jobs
- Send real money via M-Pesa or any payment system
- Log into external accounts for you

You stay in full control of applications and payments.

## How to run on GitHub

1. Create a new repository
2. Upload these files:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. Go to **Settings → Pages**
4. Source: Deploy from branch → `main` → `/ (root)`
5. Save

Your app will be live at:  
`https://YOUR-USERNAME.github.io/REPO-NAME/`

## Local use

Just open `index.html` in any modern browser.
